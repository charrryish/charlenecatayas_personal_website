CHARLENE JOY — INTERACTIVE PERSONAL WEBSITE

FILES
- index.html: website content and interactions
- style.css: visual design and responsive layout
- script.js: interactive features
- images/: copy your existing images folder here to preserve your photos

NEW INTERACTIONS
1. Pick a Mood, Find My World — four choices reveal a personal note and a link to a related section.
2. charlene.exe — a simulated command console with about, projects, dreams, and funfact commands. It is a playful interface, not a real system terminal.
3. Leave a Little Note — visitors choose a predefined note. It is temporary and is not sent or saved to a server.
4. Tap a Memory — Polaroid cards open a story modal with what happened, why it matters, and what it means. Replace the sample reflections with your own details if you want them to be more specific.
5. Behind the Build — each project card expands to show its goal, tools or focus, challenge, and what could be improved next.

SETUP
1. Extract the ZIP.
2. Copy the images folder from your existing website into this folder. Keep filenames unchanged.
3. Keep index.html, style.css, script.js, and images/ together.
4. Open index.html in your browser.

NOTE
The uploaded current website files did not include the actual image files, so the images folder must be copied from your existing project.
